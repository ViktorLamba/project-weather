Добро пожаловать в документацию Project-weather!
=================================================

**Project-weather** - это веб-приложение для получения актуальной информации о погоде по названию города или географическим координатам.

.. toctree::
   :maxdepth: 2
   :caption: Содержание:
   :hidden:

   Project_weather

Быстрый старт
-------------

Чтобы начать работу с приложением:

1. **Установите зависимости**:

   .. code-block:: bash

      pip install -r requirements.txt

2. **Запустите приложение**:

   .. code-block:: bash

      python main.py

3. **Откройте в браузере**:

   .. code-block:: bash

      http://localhost:5000

Основные возможности
--------------------

**Поиск по названию города** - введите название города на русском или английском

**Поиск по координатам** - укажите широту и долготу

**Текущая погода** - температура, влажность, скорость ветра

**Прогноз на день** - минимальная и максимальная температура

**Подробное описание** - текстовое описание погодных условий

API Endpoints
-------------

================== ====================== ===================================
Endpoint           Метод                  Описание
================== ====================== ===================================
``/``              GET                    Главная страница приложения
``/weather``       GET                    JSON API для получения погоды
``/weather-page``  GET                    Страница с интерфейсом погоды
================== ====================== ===================================

Примеры использования API
-------------------------

.. code-block:: bash

   # Получить погоду по названию города
   curl "http://localhost:5000/weather?city=Москва"

   # Получить погоду по координатам
   curl "http://localhost:5000/weather?lat=55.7558&lon=37.6173"

.. code-block:: json

   {
     "status": 0,
     "data": {
       "name": "Москва",
       "main": {
         "temp": 15.5,
         "temp_min": 12.0,
         "temp_max": 18.0
       },
       "weather": [{
         "description": "Ясно",
         "main": "Clear"
       }]
     }
   }

Структура проекта
-----------------

   project-weather/
   ├── app/

   │   │   └── controller.py    # Основная бизнес-логика

Используемые технологии
-----------------------

* **Backend**: Python, Flask
* **Frontend**: HTML, CSS, JavaScript
* **API**: Open-Meteo
* **Документация**: Sphinx
* **База данных**: Postgres
